Landing pages are made for ads and search campaigns. Each live landing page has a template of its own, so its
words and photos are in the theme editor and a change affects only that page. There are two families:

| Family | Templates | Pages |
|---|---|---|
| **Long landing pages** | **landing-cnc**, **landing-orange-county**, **landing-buy-a-3d-scanner** | /pages/3d-scanning-services-for-cnc, /pages/3d-laser-scanning-orange-county, /pages/buy-a-3d-scanner |
| **Short landing pages** | **landing-short-** + address (5 templates) | /pages/reverse-engineering-company, /pages/3d-scanning-free-estimates, /pages/3d-scanner-reverse-engineering-los-angeles, /pages/3d-scanner-reverse-engineering-orange-county, /pages/3d-mobile-laser-scanning-services-orange-county |

Two more campaign pages are built the same way and are described at the end of this page:
/pages/3d-laser-scanning-for-boats (template **3d-laser-scanning-for-boats**) and
/pages/3d-scanner-reverse-engineering (template **3d-scanner-reverse-engineering**).

The theme also keeps two shared layouts, **landing** and **landing-short**, that a new landing page can start
from. See [The shared landing layouts](#the-shared-landing-layouts).

<Note>
Every section on these pages sits in the ruled frame of the site (see [Section layout](/blocks/section-layout)).
The section names below are the names you see in the theme editor sidebar.
</Note>

## Long landing pages

photo, then rows of cards, photos and calls. Each one has its own set of sections, so they're described one by
one. Everything on them is typed in the theme editor, except the FAQ questions on the Orange County page.

### Text from the page's own fields

The hero of a short landing page isn't typed in the theme editor. It reads fields of the page record in the
Shopify admin (**Online Store → Pages** → the page → **Metafields**):

| On the page | Page field |
|---|---|
| The title (H1) | The headline field. When it's empty, the page **Title** is used. |
| The intro under the title | The hero subheading field. |
| The heading above the form | **Form heading** |
| The form button | **Form button label** |
| The wide photo under the hero | The hero image field. |

In the theme editor these settings show the name of the connected field instead of a text box. See
[Text that comes from the page's own fields](/editing-pages/how-pages-work#text-that-comes-from-the-pages-own-fields).

The form itself is the short version of the quote form: **Full name**, **Email** and **Phone**, with no project
description. Its messages go to the store's sender email, like every form on the site.

## The shared landing layouts

The templates **landing** and **landing-short** hold the original landing layouts. The live landing pages now
use their own templates, which were built from these two. Keep them as they are: they're a starting point for
a new landing page.

- **landing-short** is the hero described in [Short landing pages](#short-landing-pages) (breadcrumbs, title,
  intro, short form, photo band), followed by the page's **Content** from the admin.
- **landing** reads almost everything from the page record: the eyebrow (**Hero eyebrow**), the title, the intro,
  chips (**Hero points**), two buttons (**Hero button 1 label** / **Hero button 1 link** and
  **Hero button 2 label** / **Hero button 2 link**) and a faint [Pixel mark](/blocks/mark) set to **Auto**
  (it shows the drawing chosen in the page's **Scan motif** field). Below the hero, the page's **Content** sits
  beside a [Sticky column](/blocks/sticky-column) with a "Get started" label and the same two buttons. The
  column is hidden below 990 pixels.

## What's safe to change

- **Words, photos and buttons** in any typed block: click the block, change it, save. Keep the existing
  [text styles](/blocks/text-styles).
- **Cards**: add, remove or reorder **Card** blocks inside a card list. See [Edit a card](/how-to/edit-card).
- **Hero texts on short landing pages**: change them in the page record, not in the theme editor.
- **Don't** change a section's **Tangent frame** or a group's **Lines** settings, and don't move a section
  above the hero. The column lines are lined up from one section to the next.
- **Don't** switch a landing page to the **landing** or **landing-short** template: it would lose the sections
  in its own template.
