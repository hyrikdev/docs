A page recipe tells you what a kind of page is made of, from top to bottom: each section, the blocks inside
it, and where its words come from. Use it when you need to find something on a page, or before you change a
page's layout.

For a short tour of the page types, see [The page types](/editing-pages/page-types). This page is the map:
every kind of page, the template it uses and the recipe that describes it.

Service, location and short landing pages have **one template per page**. The template is named after the
page's web address: the Chicago page (/pages/chicago) uses **location-chicago**. A change in that template
changes only that page.
</Note>

## How a page picks its template

Every page in the Shopify admin has a **Theme template** setting. It names the layout the page uses. Blog
posts and products have the same setting.

<Steps>
  <Step title="Open the page in the admin">
    Go to **Online Store → Pages** and click the page, for example "3D scanning Chicago".
  </Step>
  <Step title="Look at Theme template">
    On the right, **Theme template** shows the template name, for example **location-chicago**.
  </Step>
  <Step title="Open that template in the theme editor">
    In the theme editor, click the page name in the top bar, choose **Pages** and pick the same template name.
    See [Open a page in the theme editor](/editing-pages/how-pages-work#open-a-page-in-the-theme-editor).
  </Step>
</Steps>

The homepage is the exception: it always uses the **Home page** template, which is the first page the theme
editor opens.

<Warning>
Don't switch a page to another page's template. The page would show the other page's words and photos,
because on this site the words live in the template. If a page looks wrong, check its **Theme template**
first.
</Warning>

## Parts every page shares

Every template sits between the same shared parts: the [announcement bar](/blocks/announcement-bar) and the
[header](/blocks/header) at the top, the [footer](/blocks/footer) and the
[mobile call bar](/blocks/sticky-bar) at the bottom (the call bar is turned off for now). In the theme editor they show in the **Header** and
**Footer** areas of the sidebar, above and below the page's own sections. Change them once and every page
follows.

## How to read a recipe

Each recipe goes through the page from top to bottom. For each section it says:

- **What you see** on the page.
- **What it's built from**: the section, the groups and the blocks inside it, with the names you see in the
  theme editor sidebar.
- **Where the words come from**: typed in the theme editor, or read from somewhere else (the page record, an
  FAQ entry, a blog).
- **What's safe to change**.

If the words of a section don't come from the theme editor, the recipe says where to change them instead.
