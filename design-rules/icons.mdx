Cards about industries, applications, benefits, reasons to choose Tangent and service options each carry a
small blue line icon. To keep the site consistent, **one idea always uses one icon**, on every page. The
homepage is the reference: if an idea has an icon on the homepage, use that icon everywhere.

The icon names below are the names you see in the **Icon** list of a card (all start with "Tangent").

## How to use an icon on a card

1. Click the **Card** in the theme editor.
2. In **Icon**, pick the icon for the card's idea from the tables below.
3. Check that the **Card list** has **Card icon** set to **Bare icon, 24px**.
4. Click **Save**.

<Warning>
- Don't give a card with a photo an icon. One marker per card.
- Don't pick an icon that already means something else on the same page or on the homepage.
- If a new idea has no icon in these tables, ask your designer to choose one, then add it here.
</Warning>

## Grids that have no icons

Not every grid gets icons. These stay without:

- lists of deliverables (what you receive) and file formats;
- comparison and capability grids;
- photo grids and galleries (the photo is the marker);
- client quotes and logos.
