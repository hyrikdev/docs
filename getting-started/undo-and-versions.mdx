---
title: "Undo and versions"
description: "How to take back a change."
---

## Before you save

- Use the **undo** and **redo** arrows in the top bar of the theme editor. You can also press
  Command + Z (Mac) or Control + Z (Windows).
- To drop every unsaved change, leave the editor without saving. Shopify asks you to confirm.

## After you save

- **Change it back by hand.** For a small change, open the same block and type the old text back, or pick the
  old image again.
- **Keep a copy before big changes.** In **Online Store → Themes**, use **…** → **Duplicate** on the current
  theme before you start. If something goes wrong, you can publish the copy and you're back where you started.
  Name the copy with the date so you know what it is.
- **Ask your developer.** Shopify keeps older versions of each theme file. A developer can bring back an
  earlier version of one page's layout without touching the rest of the site.

<Note>
Pages, blog posts, menus and FAQ entries live in the Shopify admin, not in the theme. A theme copy doesn't
back them up, and publishing an older theme doesn't change them.
</Note>

## Hide instead of delete

If you're not sure a block should go, hide it instead of removing it. A hidden block keeps its text and
images, and you can show it again later. See [Hide a block](/editing-pages/editing-content#hide-a-block).
