The site has two blogs:

| Blog | Address | Used for |
|---|---|---|
| **News** | /blogs/news (titled "Blog" on the site) | Articles about 3D scanning, reverse engineering and CAD. |
| **Case studies** | /blogs/case-studies | Project stories. The latest ones also appear on some service pages. |

## Write a post

<Steps>
  <Step title="Start a new post">
    Go to **Online Store → Blog posts** and click **Add blog post**.
  </Step>
  <Step title="Title and content">
    Type the **Title** in sentence case. Write the text in **Content**. Use the heading buttons for
    subheadings (start with **Heading 2**), and the list buttons for lists.
  </Step>
  <Step title="Excerpt">
    Write a one- or two-sentence summary in **Excerpt**. It shows on the post card in the blog list
    (cut after three lines).
  </Step>
  <Step title="Image">
    Add the featured image. It shows on the post card and at the top of the post. Add alt text that describes
    the photo.
  </Step>
  <Step title="Organization">
    Pick the **Blog** (News or Case studies). Add **Tags**: use existing tags such as "3D laser scanning" or
    "Reverse engineering". Each tag becomes a filter chip on the blog page.
  </Step>
  <Step title="Search engine listing">
    Click **Edit** next to **Search engine listing** to set the page title and meta description. See
    [Pages and SEO](/admin/pages-and-seo#the-search-engine-listing).
  </Step>
  <Step title="Publish">
    Under **Visibility**, choose **Visible** (or set a date), then click **Save**.
  </Step>
</Steps>

## Links inside a post

<Tabs>
  <Tab title="Links to Tangent pages">
    Link to the page's short address, starting with `/pages/`. For example:

    - `/pages/reverse-engineering`
    - `/pages/3d-scanning-services`
    - `/pages/contact-us`

    Don't use old addresses from the previous website, such as `usetangent.com/services/...`. Shopify can't
    redirect addresses that start with `/services/`, so those links would show an error page.
  </Tab>
  <Tab title="Links to other websites">
    Paste the full address, starting with `https://`. The site opens it in a new tab by itself: you don't need
    to tick "Open in a new window".
  </Tab>
</Tabs>

<Tip>
To check a link, preview the post and click it. A Tangent link stays in the same tab; a link to another site
opens a new tab.
</Tip>

## Tags and filter chips

The chips at the top of the blog page are made from the tags of the posts.

- A new tag adds a new chip. Reuse existing tags so the row of chips stays short.
- Type tags exactly as the existing ones, so you don't create a near-duplicate chip.
- To leave a tag out of the chips, add it to **Tags to leave out** on the **Blog tags** block in the theme
  editor (template **blog**).

## Edit or hide a post

- Open the post in **Online Store → Blog posts**, change it and click **Save**.
- To take a post off the site without deleting it, set **Visibility** to **Hidden**.
