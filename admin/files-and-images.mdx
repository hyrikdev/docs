---
title: "Files and images"
description: "Where uploaded images live, and how to give them alt text."
---

Every image used on the site is stored in **Content → Files** in the Shopify admin. When you upload an image in the
theme editor, it lands here too.

## Upload images

1. Go to **Content → Files**.
2. Click **Upload files**, or drag the files onto the page.
3. The images are now available in every image picker in the theme editor.

Before you upload:

- Give the file a clear name, for example `chicago-wheel-scan.jpg`, not `IMG_4032.jpg`. Search engines read file
  names, and you'll find the image again more easily.
- Make photos at least 1600 pixels wide and under about 1 MB.

## Add alt text

Alt text describes the image for people who use screen readers and for search engines.

1. Go to **Content → Files** and click the image.
2. Fill in **Alt text**.
3. Click **Save**.

The alt text belongs to the file, so it's the same everywhere the image is used.

**Good alt text** says what the photo shows, in one short sentence:

- "Technician scanning a car wheel with a handheld laser scanner"
- "Color deviation map of a scanned bracket"
- For a client logo: the company name shown on the logo.

**Avoid** "image", "photo of", the file name, or a list of keywords.

## Replace or delete images

- To use a different image on a page, change it in the theme editor. See [Replace an image](/how-to/replace-image).
- Don't delete files that may still be used. A deleted image leaves an empty frame wherever it was used. If in
  doubt, leave it: unused files do no harm.
