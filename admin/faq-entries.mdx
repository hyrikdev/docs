title: "FAQ entries"
description: "Where the questions and answers are stored."
---

Questions and answers are stored as entries in the Shopify admin, so the same list can be shown on a page and
read by search engines. Each question is an **FAQ** entry. Each page's set of questions is an
**FAQ category** entry.

## Where to find them

1. In the Shopify admin, go to **Content → Metaobjects**.
2. Click **FAQ** to see all the questions, or **FAQ category** to see the categories.

## An FAQ entry

| Field | What it holds |
|---|---|
| **Question** | The question, in sentence case, ending with a question mark. |
| **Answer** | The answer. You can use bold, lists and links. |
| **Category** | The page the question belongs to. Required. |

## An FAQ category entry

| Field | What it holds |
|---|---|
| **Name** | The name of the category. It shows only in the admin and the theme editor, never on the site. Name it after its page so it's easy to find. |

## Common changes

- **Change a question or answer:** open the **FAQ** entry, edit it, click **Save**. Every page that shows its
  category updates.
- **Add a question:** see [Add a FAQ question](/how-to/add-faq-question).
- **Move a question to another page:** change its **Category**.
- **Remove a question:** open the entry and delete it. Make sure you mean it: a deleted entry can't be brought
  back. If you're not sure, move it to a category that no page uses.

<Note>
A new question appears at the end of its page's list. The order follows when the entries were created.
</Note>
