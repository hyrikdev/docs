Every page on the site, such as /pages/chicago or /pages/about-us, has a record in the Shopify admin. The record
holds the page title, its web address, its search engine listing and the template it uses. The design and most
of the words are in the template, which you edit in the theme editor.

<Note>
Shopify sometimes moves items in the admin menu. If you can't find something under **Online Store**, look under
**Content**, or type its name in the search bar at the top of the admin.
</Note>

## Find a page

1. In the Shopify admin, go to **Online Store → Pages**.
2. Search for the page by its title, for example "Chicago".
3. Click the page to open it.

## What's on the page record

| Field | What it does |
|---|---|
| **Title** | The page's name. It shows in the breadcrumbs and, on some pages, as the main heading. |
| **Content** | The body text. Only plain pages and the overview pages show it. On service, location and landing pages the words are in the theme editor instead. |
| **Visibility** | **Visible** pages are on the site. **Hidden** pages aren't. |
| **Theme template** | Which template the page uses, for example **location-chicago**. Don't change it unless you're setting up a new page. |
| **Search engine listing** | The title and description shown in Google results, and the web address. |
| **Metafields** | Extra fields some templates read, such as **Form heading** on the short landing pages. |

## The search engine listing

The search engine listing is what Google and other search engines show for the page.

1. Open the page.
2. Scroll to **Search engine listing** and click **Edit** (the pencil).
3. Change the fields:
   - **Page title**: the blue title in search results. Aim for 50–60 characters. Put the main keyword first and
     end with "Tangent Solutions".
   - **Meta description**: the gray text under it. Aim for 120–160 characters. Say what the page offers and where.
   - **URL handle**: the end of the web address. Don't change it on existing pages (see the warning).
4. Click **Save**.

<Warning>
Changing the **URL handle** of a live page breaks links to it from Google, ads and other sites. If you must,
keep **Create a URL redirect** ticked when Shopify offers it. Remember that the page's template name stays the
same: **location-chicago** keeps its name even if the address changes.
</Warning>

For a step-by-step version, see [Change a page's SEO title](/how-to/change-seo-title).

## Products and blog posts

The scanner product and every blog post have the same **Search engine listing** box. Edit it the same way in
**Products** and in **Online Store → Blog posts**.
