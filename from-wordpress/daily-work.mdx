Here are the jobs that come up most, side by side. Each one links to the step-by-step page in this guide.

## At a glance

| Job | In WordPress | In Shopify | Step by step |
|---|---|---|---|
| Change the words on a page | Open the page in Elementor, click the text, edit, **Update**. | Open the page's template in the theme editor, click the text, edit, **Save**. | [Editing content](/editing-pages/editing-content) |
| Change a card in a grid | Edit the widget in Elementor. | Click the **Card** inside the **Card list** and edit its **Title**, **Text** or **Icon**. | [Add or edit a card](/how-to/edit-card) |
| Swap an image | Upload to the Media Library, pick it in the page builder. | In the theme editor, click the image, then **Change**. New uploads land in **Content → Files**. | [Replace an image](/how-to/replace-image) |
| Write a blog post | **Posts → Add New**. | **Online Store → Blog posts → Add blog post**. Pick the blog (**News** or **Case studies**). | [Add a blog post](/how-to/add-blog-post) |
| Add a FAQ question | Edit the FAQ on the page. | Add an **FAQ** entry in **Content → Metaobjects** and pick its category. | [Add a FAQ question](/how-to/add-faq-question) |
| Change a menu | **Appearance → Menus**. | **Online Store → Navigation**, then **Save menu**. | [Menus](/admin/menus) |
| Change the SEO title | The Yoast box under the page. | **Search engine listing** at the bottom of the page record, then **Edit**. | [Change a page's SEO title](/how-to/change-seo-title) |
| Change the phone number | Find and edit each place it appears. | Several places, listed on one page. | [Change the phone number](/how-to/change-phone-number) |
| Redirect an old address | A redirect plugin, or your web host. | **Online Store → Navigation → URL redirects**. | [URL redirects](/admin/url-redirects) |
| Preview before publishing | **Preview** button, **Save draft**. | Work on a copy of the theme and use **Preview**, or check the editor's preview before **Save**. | [Preview and publish](/getting-started/preview-and-publish) |
| Hide a page | Set it to **Draft** or **Private**. | Set its **Visibility** to **Hidden**. | [Pages and SEO](/admin/pages-and-seo) |
| Undo a mistake | Restore a revision. | **Undo** before you save; after saving, change it back or restore a theme copy. | [Undo and versions](/getting-started/undo-and-versions) |
| Add a new city page | Add a page in the page builder. | A new page record, a new template and a menu item. | [Add a location page](/how-to/add-location-page) |

## What feels different

### You first find the template

In WordPress you opened the page and its layout came with it. In Shopify you open the theme editor and pick the
page's **template** from the list at the top. Each service and location page has its own, named after its
address, for example **location-chicago** for /pages/chicago. See
[Open a page in the theme editor](/editing-pages/how-pages-work#open-a-page-in-the-theme-editor).

### Some words aren't in the theme editor

Most text is typed in the theme editor. A few kinds of content live in the Shopify admin instead:

- **FAQ questions** are entries in **Content → Metaobjects**. See [FAQ](/blocks/faq).
- **Blog posts and case studies** are in **Online Store → Blog posts**. The case study rows on service pages
  pick up the latest ones by themselves.
- **Menus**, including the list of cities on the locations overview, are in **Online Store → Navigation**.
- On a few pages, some texts come from the page's own fields. See
  [Text that comes from the page's own fields](/editing-pages/how-pages-work#text-that-comes-from-the-pages-own-fields).

### Save means live

On the live theme there's no draft step: **Save** puts the change on the site straight away. For anything bigger
than a typo, work on a copy of the theme first. See [Preview and publish](/getting-started/preview-and-publish).

<Warning>
Menus, pages, blog posts, FAQ entries and images are shared by every theme. Changing them while you work on a
theme copy changes the live site too.
</Warning>

### The style is already set

In Elementor you often set colors, fonts and spacing yourself. Here the Tangent blocks carry the style: you
change the words and the pictures, and the look stays the same. Leave the **Tangent style** settings as they
are, and follow the [design rules](/design-rules/do-and-dont).

### Images are picked in a setting

You don't place an image on the page directly. You choose it in the block's **Image** setting,
either one already in **Content → Files** or a new upload. Alt text belongs to the file in **Content → Files**,
so it's the same everywhere the image is used. See [Files and images](/admin/files-and-images).

### No revision history

WordPress kept a list of revisions for each page. Shopify doesn't keep one for pages or posts. Before a big
change, duplicate the theme so you have a copy to go back to, and copy long texts somewhere safe before you
rewrite them. See [Undo and versions](/getting-started/undo-and-versions).
