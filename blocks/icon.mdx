The **Icon** block shows one small icon. On this site it's a blue line icon from the **Tangent** set, placed
in a group next to a short text or above a title. It's not the same as the icon of a **Card**: cards in a
**Card list** pick their icon in the card's own **Icon** setting (see [Card list](/blocks/card-list)).

## What it looks like

The site uses two of its **Tangent style** looks:

- **Accent**: a bare blue line icon, 24 pixels wide. For example the precision target beside "0.025mm accuracy"
  in the homepage hero.
- **Badge**: a small filled blue square with the icon in it. With a 12-pixel icon it makes an 18-pixel badge.
  For example the check marks before "Fast turn-around" and "Expert technicians" on the homepage.

## Block settings

| Setting | What it does |
|---|---|
| **Icon** | The icon to show. Pick one of the **Tangent** icons (their names all start with "Tangent"). The list also has the theme's own icons (food, clothing, social networks…), which this site doesn't use. See [Icons](/design-rules/icons) for which icon means what. |
| **Image icon** | An uploaded picture to use instead of an icon. Not used on this site. |
| **Width** | The icon's size in pixels. The site uses 24 for icons, 22 in the contact rows of the short landing pages, and 12 for badges. |
| **Link** | Makes the icon a link. |
| **Open link in new tab** | Opens the link in a new tab. Links to other websites open in a new tab anyway. |
| **Color** | A custom color. Leave it empty: the **Tangent style** sets the blue. |
| **Tangent style** | **Accent** (blue icon), **Badge** (filled blue square), **Tile** (bordered square) or **None** (the theme's own look). |

## Where it's used on the site

**The homepage**, in four sections:

| Section | Icons |
|---|---|
| **Hero** | **Tangent target** (0.025mm accuracy), **Tangent truck** (in-house + mobile scanning), **Tangent clock** (same-day service), **Tangent plane** (serving aerospace, auto, medical and more). |
| **Services** | **Tangent scan**, **Tangent cube**, **Tangent pen**, **Tangent chart**, **Tangent file**, **Tangent truck**, one per service. |
| **Why Tangent** | **Tangent plane**, **Tangent target** and **Tangent clock**, plus five **Tangent check** badges before the short list of strengths. |
| **Scanning options** | **Tangent scan**, **Tangent pin**, **Tangent truck**. |

**The short landing pages** (five of them), in the **Contact** section: **Tangent pin** before the address and
**Tangent clock** before the opening hours, both **Accent** at 22 pixels.

## Notes

<Warning>
Same idea, same icon. Before you pick an icon, check the [icon table](/design-rules/icons): if the homepage
already uses an icon for that idea, use the same one. Don't put icons in boxes (the **Tile** style isn't used
on the site).
</Warning>

- To add an icon beside a text, put the **Icon** and the **Text** in the same group, as on the homepage hero.
  Copy an existing group rather than building a new one.
