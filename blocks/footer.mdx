## What it does

The footer closes every page of the site: the logo and a short text about Tangent, the industries Tangent
serves, the Helpful Links menu, the contact details, the social icons and the copyright line. It's one shared
section, so a change here shows on every page at once.

## Where to find it

<Steps>
  <Step title="Open any page">
    In the theme editor, open any page. The footer is the same on all of them.
  </Step>
  <Step title="Select the footer">
    At the bottom of the sidebar, in the **Footer** group, select **Footer** for its own settings.
  </Step>
  <Step title="Select a part">
    Open **Footer** and the groups inside it, then select the block you want to change (see the table below).
  </Step>
</Steps>

To add a block, select a group inside the footer and choose **Add block**, then the block, for example **Add block › Text**.

## What's in it

The footer is built from groups of ordinary blocks, so you edit it like any page:

| Part | Block | How to change it |
|---|---|---|
| Logo | **Logo** | Follows the logo in **Theme settings → Logo and favicon**. |
| About text | **Text** (style **Body small**) | Click it and edit the words. |
| "Industries we serve" | **Text** (style **Chips**) | Edit the bulleted list: one industry per bullet. |
| "Helpful links" | **Menu** | Shows the **Helpful Links** menu. Edit that menu in **Online Store → Navigation**. See [Menus](/admin/menus). |
| "Contact us" | **Text** (style **Body small**) | Edit the phone, email, meeting link, hours and address. Each is its own line; all but the hours are links. |
| "Get connected" | **Social media links** | Paste the Facebook, Instagram and YouTube page addresses. Empty fields hide their icon. |
| Copyright line | **Text** (style **Mono**) | Update the year when it changes. |

The headings ("Industries we serve", "Contact us", "Get connected") are **Text** blocks with the style
**Eyebrow, leading mark**. For the **Text** styles, see [Text styles](/blocks/text-styles); for groups, see
[Section layout](/blocks/section-layout).

<Note>
The phone number appears twice in the footer: in the "Contact us" text and as the **Call Now** link in the
Helpful Links menu. Update both when the number changes. See [Change the phone number](/how-to/change-phone-number).
</Note>

## Settings

On **Footer** itself, keep **Rails** at **Rails, no inner padding** and **Top border across the page** on, as on
every other section. In the blocks, the settings you'll use are the **Menu** block's **Menu** and **Heading**, and
the **Social media links** addresses. The tables for **Logo**, **Menu** and **Social media links** count every
copy of those blocks on the site, not only the footer's.

## Data and metafields

| Where | What lives there |
|---|---|
| **Online Store → Navigation** → **Helpful Links** | The links under "Helpful links", including **Call Now**. |
| **Theme settings → Logo and favicon** | The logo image. |
| Theme editor → footer **Text** blocks | The about text, industries, contact details and copyright line, typed in place. |

## Limitations

- The footer is shared: you can't give one page a different footer.
- The contact details are typed text, not read from **Settings → Store details**. Change them here when they
  change.
- A **Utilities** section (copyright, policy links and social icons) is in the **Footer** group but
  turned off (the eye icon in the sidebar). Leave it off: the footer above already has the copyright line and
  the social icons.
- The **Mobile sticky CTA** section in the same group is the [mobile call bar](/blocks/sticky-bar). It's turned
  off for now.
