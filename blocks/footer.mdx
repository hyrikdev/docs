## What's in it

The footer is made of groups of ordinary blocks, so you edit it like any page:

| Part | Block | How to change it |
|---|---|---|
| Logo | **Logo** | Follows the logo in **Theme settings → Logo and favicon**. |
| About text | **Text** (style **Body small**) | Click it and edit the words. |
| "Industries we serve" | **Text** (style **Chips**) | Edit the bulleted list: one industry per bullet. |
| "Helpful links" | **Menu** | Shows the **Helpful Links** menu. Edit that menu in **Online Store → Navigation**. See [Menus](/admin/menus). |
| "Contact us" | **Text** (style **Body small**) | Edit the phone, email, meeting link, hours and address. Each is a line with a link. |
| "Get connected" | **Social media links** | Paste the Facebook, Instagram and YouTube page addresses. Empty fields hide their icon. |
| Copyright line | **Text** (style **Mono**) | Update the year when it changes. |

<Note>
The phone number appears twice in the footer: in the "Contact us" text and as the **Call Now** link in the
Helpful Links menu. Update both when the number changes. See [Change the phone number](/how-to/change-phone-number).
</Note>

## Footer settings

Click **Footer** itself to see **Rails** and **Top border across the page**. Keep **Rails, no inner padding**
and the top border on, as on every other section.
