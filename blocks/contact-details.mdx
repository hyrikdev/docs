The **Contact details** block shows Tangent's contact information as ruled rows, each with a small blue line
icon: phone, email, meeting link, address and opening hours. Each row is optional. The phone and email rows are
links: a click calls the number or opens a new email.

## What it looks like

| Row | Icon | Shows |
|---|---|---|
| Phone | Phone | The phone number, as a link that calls it. |
| Email | Envelope | The email address, as a link that opens a new email. |
| Schedule link | Calendar | A link to book a meeting, for example "Schedule a meeting". |
| Address | Pin | The address, as a link to the map when **Address link** is set. |
| Hours | Clock | The opening hours. |

Each row can also show a small label before the value (such as "Phone" or "Office hours"), in a column of its
own. Without labels, the rows show only the icon and the value.

## Block settings

| Setting | What it does |
|---|---|
| **Phone** | The phone number. Leave it empty to use the store phone from **Settings → Store details** in the admin. |
| **Phone row label** | Optional label before the phone number. Leave it empty for no label. |
| **Hide the phone row** | Leaves the phone row out, even the store phone. For a list that sits next to a call button. |
| **Email** | The email address. |
| **Email row label** | Optional label before the email. |
| **Schedule link label** and **Schedule link** | The text and the address of a booking link, for example a Calendly page. The row shows only when both are filled in. |
| **Open schedule link in a new tab** | Opens the booking page in a new tab. Links to other websites open in a new tab anyway. |
| **Address** | The address. |
| **Address row label** | Optional label before the address. |
| **Address link** | Optional Google Maps link for the address. |
| **Hours** | The opening hours. |
| **Hours row label** | Optional label before the hours. |
| **Top divider** | A thin line above the first row. |
| **Padding** (**Top**, **Bottom**) | Space above and below the list. |

## Where it's used on the site

- **Every service page (13) and every location page (46)**, in the closing **Quote** section, next to the quote
  form. These show the phone number, the email, a "Schedule a meeting" link, the address and the hours,
  without labels.
- **The contact page**, under the call and meeting buttons, with the labels **Phone**, **Email**, **Address**
  and **Office hours** and a map link on the address. The meeting link is a button there, not a row.
- **The free consultation page**, in the section with the map: two lists with only the address and the
  hours (the phone row is hidden).

## Notes

<Warning>
Every page has its own **Contact details** block, so a change on one page doesn't change the others. If the
phone, email, address or hours change, ask your developer to update every page in one go. See
[Change the phone number](/how-to/change-phone-number).
</Warning>

- The quote form next to the contact details is its own block. See
  [Contact details and quote form](/blocks/contact-and-quote-form#quote-form).
- The pages are explained section by section in [Contact pages](/page-recipes/contact-pages).
