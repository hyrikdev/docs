Every heading, label and paragraph is a **Text** block. Its look comes from one setting: **Tangent style**.
When it's set, it overrides the theme's own **Preset** under **Typography**, so you don't need to touch
the font, size or color.

## The styles you'll use most

| Tangent style | What it looks like | Use it for |
|---|---|---|
| **Eyebrow** | Small mono text with a blue square before and after. | The short label above a section heading, such as "What we do". |
| **Eyebrow, leading mark** | Small mono text with one blue square before it. | Labels above left-aligned headings and footer column titles. |
| **Display (hero title)** | The largest blue heading. | The main title (H1) at the top of a page. Only once per page. |
| **Heading large** | A large blue heading. | Section headings. |
| **Heading medium** | A medium blue heading. | Section headings in smaller sections. |
| **Card title** | Black title. | Titles inside cards and cells. Card titles stay black. |
| **Lede** | Larger gray text. | The intro paragraph under a heading. |
| **Lede, wide** | The same, in a wider column. | Intros in wide hero areas. |
| **Body small** | Regular small gray text. | Text inside cards and cells. |
| **Long-form text** | Comfortable reading style for long text. | Long articles and policy text. |
| **Label** | Small text in a single line. | Short labels beside icons. |
| **Mono** | Small mono text. | Fine print, such as the copyright line. |
| **Chips** | Each line becomes a small bordered tag in a wrapping row. | Short lists like industries or highlights. |
| **Ticks, 2 columns** / **Ticks, inline** | Each list item gets a blue check mark. | Short feature lists, such as "Fast turn-around, Same day service". |

## Special styles

These styles shape one particular layout. They're already set on the pages that use them:
**Stat value**, **Statement title**, **Statement title, long**, **Statement text**, **Row heading**,
**Two-column prose**, **Split text**, **Closing line**, **Closing line, cell foot**, **Step names**,
**Row text**, **Chips, large** and **Price**.

If you need one of these on a new section, copy the section from a page that already has it rather than
building it from scratch.

## Heading levels

The style controls the look. The heading level (H1, H2, H3) is set inside the text box and tells search engines
how the page is organized.

- Each page has **one H1**: the page title at the top.
- Section headings are **H2**.
- Card titles are **H3**.

## Other Text block settings

| Setting | What it does |
|---|---|
| **Page title when blank** | Shows the page's title as the main heading when the text is empty. |
| **Hide section when blank** | Hides the whole section on the live site when this text is empty. The editor still shows it so you can fill it in. |

## Checklist

The **Checklist** block shows a short list with blue check marks, for example under a hero. Its settings,
including **Items from a field**, are on the [Checklist](/blocks/checklist) page.
