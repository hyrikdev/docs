## What it does

Shows a few short items, each one a small mono text in a thin square frame with a blue check mark in front of
it. You type the items in one box, one item per line. It's made for short facts, such as the benefits of a
service, not for long sentences.

  <img src="/images/location-cad-row.png" alt="The CAD row of the Chicago page: under the label 'Benefits of Chicago 3D scanning service', six items in thin square frames, each with a small blue check mark" />
</Frame>

The site has a checklist on 22 of the 46 location pages, in the **CAD row** section, under the text about scan
data (for example "Scan data is precise up to 0.025mm."). Almost every one of these pages has its own items.

## Where to find it

<Steps>
  <Step title="Open the page">
    In the theme editor, open the location page's template (for example **location-chicago**).
  </Step>
  <Step title="Select the block">
    In the sidebar, open the **CAD row** section, then the **CAD row** group and the **CAD copy** group inside
    it, and select **Checklist**.
  </Step>
</Steps>

To add one, select a section or group and choose **Add block › Checklist**.

## Settings

To change an item, edit its line in **Items**. **Layout** decides how the items sit: side by side, one under
the other, or in columns. All 22 location checklists use **List**, **Light**, **Body** and **Large**.

{/* settings:begin source=block:ts-checklist level=3 */}

Used 22 times across 22 page layouts and header/footer groups. In **Tangent uses**, a number in brackets is how many of those copies use that value.

| Setting | Values | Default | Tangent uses | Notes |
|---|---|---|---|---|
| **Items** | Text | “0.025mm accuracy · In-house + mobile scanning · …” | Set on all | One item per line. Empty lines are skipped. Keep each item to a few words. |
| **Items from a field** | Rich text | — | Empty | Links the list to a multi-line field of the page: each line becomes an item and Items is not used. A page whose field is blank shows no list. |
| **Layout** | Inline, List, Grid | Inline | List | Inline: side by side, wrapping onto the next line. List: one under the other. Grid: in columns, as many as fit. |
| **Background** | Light, Dark | Light | Light | Match the section background, so the text and check marks stay easy to read. |
| **Text color** | Body, Heading | Body | Body | Body is gray, Heading is black. |
| **Text size** | Small, Medium, Large | Small | Large | — |
| **Bold text** | On, Off | Off | Off | — |

{/* settings:end */}

## Data and metafields

None. The items are typed in the block. **Items from a field** can read them from a page field instead, but no
page does.

## Limitations

- The **Checklist** block isn't the same as the **Ticks** styles of a **Text** block. Ticks are plain text
  lines with a check mark, typed as a bulleted list inside a Text block. See [Text styles](/blocks/text-styles).
- Keep each item short: a few words, or one short sentence.
- When you add a checklist to another location page, copy the settings of an existing one, so all location
  pages look the same.
- Each page has its own items: a change on one page doesn't change the others. See
  [How the pages are set up](/editing-pages/how-pages-work).
