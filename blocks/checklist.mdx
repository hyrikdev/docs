The **Checklist** block shows a few short items, each one with a small blue check mark. You type the items in
one box, one item per line. It's made for short facts, such as the benefits of a service, not for long sentences.

## What it looks like

Each item is a small mono text in a thin square frame, with a blue check mark in front of it. The **Layout**
setting decides how the items sit:

- **Inline**: side by side in a row, wrapping onto the next line when there's no more room.
- **List**: one under the other.
- **Grid**: in columns, as many as fit the width.

<Note>
The **Checklist** block isn't the same as the **Ticks** styles of a **Text** block. Ticks are plain text lines with
a check mark, typed as a bulleted list inside a Text block. See [Text styles](/blocks/text-styles).
</Note>

## Block settings

| Setting | What it does |
|---|---|
| **Items** | The list. One item per line. Empty lines are skipped. |
| **Items from a field** | Connects the list to a multi-line text field of the page instead. Each line of the field becomes an item and **Items** above is not used. If the field is blank on a page, that page shows no list. Leave it empty to use **Items**. |
| **Layout** | **Inline**, **List** or **Grid** (see above). |
| **Background** | **Light** or **Dark**. Match the section background, so the text and check marks stay easy to read. |
| **Text color** | **Body** (gray) or **Heading** (black). |
| **Text size** | **Small**, **Medium** or **Large**. |
| **Bold text** | Makes the items bold. |

## Where it's used on the site

The checklist is on 22 of the 46 location pages, in the **CAD row** section, under the text about scan data
(for example "Scan data is precise up to 0.025mm."). Each of these pages has its own items. They all use the
same settings: **Layout** **List**, **Background** **Light**, **Text color** **Body** and **Text size**
**Large**.

## Notes

- Keep each item short: a few words, or one short sentence.
- When you add a checklist to another location page, copy the settings above so all location pages look the
  same.

<Tip>
To change an item on one page, open that page's template in the theme editor, click the **Checklist** block in
the **CAD row** section and edit the line in **Items**. See
[How the pages are set up](/editing-pages/how-pages-work).
</Tip>
