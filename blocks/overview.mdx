The site uses a small set of blocks again and again. Learn these and you can edit any page.

| Block (as named in the editor) | What it's for | Page |
|---|---|---|
| **Card list** with **Card** blocks | Grids of cards: industries, benefits, options, galleries, steps, quotes, link cells | [Card list](/blocks/card-list) |
| **Text** | Every heading, label and paragraph | [Text styles](/blocks/text-styles) |
| **Checklist** | A short list of ticked items | [Text styles](/blocks/text-styles#checklist) |
| **Button** | Call buttons, quote buttons, links | [Buttons](/blocks/buttons) |
| **Image** | Photos, logos and drawings | [Images](/blocks/images) |
| **FAQ category** | The list of questions on a page | [FAQ](/blocks/faq) |
| **Breadcrumbs** | The "Home / Services / page" trail at the top | [Breadcrumbs](/blocks/breadcrumbs) |
| **Project gallery** | The portfolio photos with the full-screen viewer | [Gallery and lightbox](/blocks/gallery) |
| **Contact details** and **Quote form** | Phone, email, address, hours and the request form | [Contact details and quote form](/blocks/contact-and-quote-form) |
| **Group**, **Section** settings, **Pixel mark** | The ruled layout, lines and faint decorations | [Section layout](/blocks/section-layout) |
| **Header** | Logo, menu, phone button, Contact us | [Header](/blocks/header) |
| **Announcement bar** | The blue bar at the very top | [Announcement bar](/blocks/announcement-bar) |
| **Mobile sticky CTA** | The Call Now / Get a Quote bar on phones | [Mobile call bar](/blocks/sticky-bar) |
| **Footer** | The bottom of every page | [Footer](/blocks/footer) |

<Note>
In the block list you may see blocks from the Horizon theme that this site doesn't use (for example product
grids or slideshows). Stick to the blocks above so the pages keep the Tangent look.
</Note>

## Settings with "Tangent" in their name

Many blocks have a group of settings called **Tangent style** (or a setting called **Tangent style**). These
give the block the Tangent look. When you add a new block, set its Tangent style to match the same kind of block
on another page.
