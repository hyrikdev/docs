## What it does

Shows a list of frequently asked questions. A click on a question opens its answer; the plus sign turns into a
minus. The questions themselves aren't typed in the theme editor: each one is an **FAQ** entry in the Shopify
admin, and each entry belongs to a **category**. The block shows every question of the category you pick.

The site has FAQ lists on 10 pages: 7 service pages, the Hawaii location page, the Orange County landing page
and the 3D scanner reverse engineering page.

## Where to find it

<Steps>
  <Step title="Open the page">
    In the theme editor, open the page's template (for example **service-3d-scanning-services**).
  </Step>
  <Step title="Select the block">
    In the sidebar, open the **FAQ** section and select **FAQ category** inside it.
  </Step>
</Steps>

To add a list to another page, select a section or group and choose **Add block › FAQ category**.

## Settings

To change which questions show, pick another **Category**. To add, change or remove a question, edit the FAQ
entries in the admin instead: see [FAQ entries](/admin/faq-entries) and
[Add a FAQ question](/how-to/add-faq-question).

Used 10 times across 10 page layouts and header/footer groups. In **Tangent uses**, a number in brackets is how many of those copies use that value.

| Setting | Values | Default | Tangent uses | Notes |
|---|---|---|---|---|
| **Category** | Entry | — | Set on all | An FAQ category entry (Content > Metaobjects > FAQ category). |

| **Output FAQPage structured data** | On, Off | On | On | Turn off if another FAQ list on the same page already outputs it. |
| **Open first question** | On, Off | Off | Off (9), On (1) | — |

## Data and metafields

| Where | What lives there |
|---|---|
| Shopify admin → **FAQ category** entries | One category per page, for example the category of the reverse engineering page. |
| Shopify admin → **FAQ** entries | Each question, with its **Question**, **Answer** and **Category**. |
| Theme editor → **FAQ category** block | Which category the page shows, and how the list looks. |

## Limitations

- Questions show in the order their entries were created in the admin, oldest first. A new question appears at
  the end of the list.
- Only the first 250 FAQ entries in the store are read. Past that, the editor shows a warning.
- If a page has a second FAQ list, turn off **Output FAQPage structured data** on one of them, so search
  engines read the questions once.
- Answers can contain links. Links to other websites open in a new tab by themselves.
