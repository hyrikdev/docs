## What it does

Shows a process as a small diagram: each step or result is a cell on the ruled grid, and arrows on the lines
between the cells show what leads to what. Each cell is a **Flow node** block inside the flow chart. The words
are real text, so search engines and screen readers read them in order.

On a large screen (990 pixels and up) the chart has 4 equal columns and 2 rows, with thin lines between the
cells. Columns 1 and 2 run the full height; columns 3 and 4 can be split into a top row and a bottom row, so
one step can branch into two results.

- A **Process step** cell shows its title only.
- A **Deliverable** cell (a result, such as a file type) has a light gray background, a small blue square, its
  title and a line under it.
- The arrows are small round marks on the line to the right of a cell.

On tablets (750 to 989 pixels) the chart has 2 columns. On phones it's a single column in block order; the
branch cells are indented, with a blue line on their left edge.

## Where to find it

<Steps>
  <Step title="Open the page">
    In the theme editor, open the **service-reverse-engineering** template.
  </Step>
  <Step title="Select the block">
    In the sidebar, open the **What we do** section and select **Flow chart**. Its cells are the **Flow node**
    blocks inside it.
  </Step>
</Steps>

To add one, select a section or group and choose **Add block › Flow chart**. To add a cell, select the flow
chart and choose **Add block › Flow node**.

## Settings

To change the words, edit the **Title** and **Line** of each node. **Position** and **Arrows** set the shape
of the chart; keep them as they are unless the shape changes.

### Flow chart

{/* settings:begin source=block:ts-flow level=4 */}

Used once across 1 page layout or header/footer group. In **Tangent uses**, a number in brackets is how many of those copies use that value.

| Setting | Values | Default | Tangent uses | Notes |
|---|---|---|---|---|
| **Show only when** | Text | — | Empty | For a layout shared by several pages: link this to a field of the page, and the chart shows only where that field equals Value. |
| **Value** | Text | — | Empty | Leave blank to always show the flow chart. |

#### Padding

| Setting | Values | Default | Tangent uses | Notes |
|---|---|---|---|---|
| **Top** | 0–100px | 0px | 0px | — |
| **Bottom** | 0–100px | 0px | 48px | — |

{/* settings:end */}

### Flow node

{/* settings:begin source=block:_ts-flow-node level=4 */}

Used 5 times across 1 page layout or header/footer group. In **Tangent uses**, a number in brackets is how many of those copies use that value.

| Setting | Values | Default | Tangent uses | Notes |
|---|---|---|---|---|
| **Title** | Text | — | Set on all | The step or result, for example Mesh File. |
| **Line** | Text | — | Set on 2 of 5 | Shown under the title, for example what a file is used for. |
| **Type** | Process step · Deliverable (muted cell, accent square) | Process step | Process step (3) · Deliverable (muted cell, accent square) (2) | Deliverable is for a result, such as a file type: a light gray cell with a small blue square. |
| **Position** | Auto · Column 1, both rows · Column 2, both rows · Columns 3 and 4, top row · Column 3, bottom row · Column 4, bottom row | Auto | Column 1, both rows (1) · Column 2, both rows (1) · 3 more | Where the cell sits on large screens. Tablets show 2 columns; phones one column in block order, with the column 3 and 4 cells indented as branches. |
| **Arrows** | None · One, to the next cell · Two, to the top and bottom rows | None | One, to the next cell (2) · None (2) · 1 more | Two is for a step that branches into the top and bottom rows. |

{/* settings:end */}

## Data and metafields

None. The words are typed in the nodes. **Show only when** can link the chart to a page field, but the site
doesn't use it.

## Limitations

- The **Position** choices are made for this shape: two steps, then a split into a top result and a bottom step
  with its own result. For a different shape, ask your developer.
- Keep the nodes in reading order in the sidebar. Phones show them in that order, one under the other.
- Placed straight in a section with the **Rails, no inner padding** frame, the chart runs from rail to rail and
  its lines meet the page's column lines. See [Section layout](/blocks/section-layout).
