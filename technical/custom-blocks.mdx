This page lists the blocks and the one section added on top of Horizon. Horizon blocks that only gained `ts_*`
settings are listed in [Architecture](/technical/architecture#settings-added-to-horizon-files).

"Used in" counts the JSON templates and section groups whose JSON contains the block type (`templates/*.json`,
`sections/*.json`). Recount after big template changes:

```bash
grep -l '"type": "ts-mark"' templates/*.json sections/*.json | wc -l
```

Editor names come from the schema `name` (resolved through `locales/en.default.schema.json` for `t:` keys).
Child blocks (prefix `_`) only appear inside their parent.

## Blocks not used by any template

These blocks exist in `blocks/` but no template or section group uses them. Most were built for the first
versions of the pages (the metaobject-driven service and location templates, or the first homepage design) and
were replaced by the card list and static blocks. They still appear in the theme editor's block picker.

| File | Editor name | What it was for |
|---|---|---|
| `faq-list.liquid` | **FAQ list** | FAQ accordion from a list of `faq` entries (replaced by **FAQ category**). |
| `industries-list.liquid` | **Industries list** | Grid of `industry` entries. |
| `service-list.liquid` | **Service list** | Grid of `service` entries linking to their web pages. |
| `ts-testimonial.liquid` | **Testimonial** | One quote card from a `testimonial` entry or typed text. |
| `ts-industry-chips.liquid` + child `industries-list` | **Industry chips** | "Industries we serve" chips band. |
| `optional-image.liquid` | **Image (optional)** | An image that renders nothing when empty (for optional dynamic sources). |
| `steps-list.liquid` + `_steps-list-item.liquid` | **Steps list** / **Step** | Numbered list on 1px lines. |
| `ts-cards.liquid` + `_ts-card.liquid` | **Card grid** / **Card** | Auto-numbered card grid. |
| `ts-stats.liquid` + `_ts-stat.liquid` | **Stats strip** / **Stat** | Strip of key figures. |
| `ts-steps.liquid` + `_ts-step.liquid` | **Process steps** / **Process step** | Numbered timeline. |
| `ts-logo-marquee.liquid` + `_ts-client-logo.liquid` | **Logo marquee** / **Client logo** | Scrolling client logos (Horizon's marquee). |
| `ts-media-frame.liquid` | **Media frame** | Image frame with an overlay slot. |
| `ts-scan-spec.liquid` + `_ts-spec-row.liquid` | **Spec card** / **Spec row** | Small spec sheet for a media frame overlay. |
| `ts-tabs.liquid` + `_ts-tab.liquid` | **Tabs** / **Tab** | Accessible tabs. |
| `ts-anchor.liquid` | **Anchor** | Invisible jump target for `/#id` links. |

<Warning>
`ts-tabs.liquid` reads `tab.settings.title` while looping its children. A parent block can't read child
settings, so every tab label falls back to "Tab". Fix it (render the label from the child block) before using
the block.
</Warning>

Before deleting an unused block, check that the live theme doesn't use it (a template created in the theme
editor arrives in the repository only after it's merged from `main`), and remember that `card-list`,
`industries-list`, `service-list` and `ts-testimonial` reference metaobject definitions in their schema (see
[Content model](/technical/content-model)). Deleting a file is a change the site owner signs off.
