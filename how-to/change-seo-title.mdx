---
title: "Change a page's SEO title"
description: "Change the title and description Google shows for a page."
---

<Steps>
  <Step title="Open the page">
    In the Shopify admin, go to **Online Store → Pages** and click the page. (For a blog post, use
    **Online Store → Blog posts**; for the scanner, **Products**.)
  </Step>
  <Step title="Edit the search engine listing">
    Scroll to **Search engine listing** and click **Edit** (the pencil).
  </Step>
  <Step title="Page title">
    Type the new title. Aim for 50–60 characters, main keyword first. For example, the 3D scanning services
    page uses "3D Scanning Services | 0.025mm Accuracy | Tangent Solutions".
  </Step>
  <Step title="Meta description">
    Write one or two sentences, 120–160 characters, saying what the page offers.
  </Step>
  <Step title="Leave the URL handle alone">
    Don't change the **URL handle** unless you have to. See the warning in
    [Pages and SEO](/admin/pages-and-seo#the-search-engine-listing).
  </Step>
  <Step title="Save">
    Click **Save**. Google picks up the change the next time it visits the page, which can take a few days to a
    few weeks.
  </Step>
</Steps>

<Note>
The SEO title is not the heading on the page. To change the heading visitors see, edit the page in the theme
editor.
</Note>
